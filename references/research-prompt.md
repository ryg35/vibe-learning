# Research プロンプト（Step 1）

**このプロンプトは Claude が実行しない。** テーマを埋めた全文をコードブロックで出力し、
ユーザーが ChatGPT など検索が有効なモデルへ投げる。返ってきた表が Step 2 の入力になる。

`[ここに入力]` を Step 0 で合意したテーマに置き換えてから渡すこと。

```
2時間 Vibe Learning｜Research

学びたいこと：
→ [ここに入力]

このテーマを「2時間で実践レベルまで学ぶ」ために必要な情報源をWebで徹底的にリサーチしてください。
あなたの役割は教材を作ることではなく、教材制作に必要な最高品質の情報源を集め、選別することです。

情報源の優先順位

1. 公式ドキュメント・一次情報
2. 原著論文・大学・公的機関
3. 著者・開発者本人による解説
4. 信頼性の高い技術記事・専門メディア
5. 良質なチュートリアル・実践記事
6. その他の補助資料

SEO目的の記事や、一次情報を薄くまとめただけの記事は極力除外してください。

出力
まず、このテーマを2時間で学ぶための重要トピックを優先順位順に整理してください。
その後、教材制作に使うべきURLを、重要度順に並べたtable（表）で出力してください。
tableの列は以下だけにしてください。

| 優先度 | ページタイトル | URL | 何を学ぶための資料か | この資料を選んだ理由 |

同じ内容なら、より一次情報に近いURLだけを残してください。
情報が古くなりやすいテーマでは最新情報を優先し、重要な仕様・主張は可能な限り複数ソースで確認してください。
教材本文やHTMLは作らないでください。
後工程で別のAIが、このリサーチ結果をもとに2時間分の教材を制作します。
```

## 返ってきた結果の見かた

- **表が5行未満** … テーマが狭すぎるか、一次情報が存在しない領域。ユーザーに再リサーチを提案する（判断はユーザーがする）
- **URLが個人ブログばかり** … 優先順位1〜3が拾えていない。同上
- **表だけで重要トピックの整理がない** … プロンプトの前半が無視されている。整理だけ追加で出してもらう

問題がなければ、表をそのまま `references/teaching-prompt.md` のリサーチ結果欄に流し込む。
