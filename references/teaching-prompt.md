# 教材生成プロンプト（Step 2）

Step 1 で返ってきたリサーチ結果を貼って使う、教材生成の仕様の原本。
Claude 自身が教材を書く場合も、この方針をそのまま守る。

**書き始める前に `material-design.md` を読む。** HTML の作りはそちらが規範。

```
2時間 Vibe Learning｜教材生成

学びたいこと：
→ [ここに入力]

リサーチ結果：
→ [ChatGPTのリサーチ結果をここに貼る]

上記のリサーチ結果をもとに、2時間で「理解 → 実践」まで到達できる学習教材をHTMLで作成してください。
あなたの役割はリサーチではなく、与えられた情報を最高に分かりやすい教材へ変換することです。

方針

* リサーチ結果の「優先度」が高い情報源を軸にする
* 新しい事実を勝手に補完せず、提供されたソースを根拠にする
* 網羅性より「重要な20%」を優先する
* 初心者でも理解できる順序に再構成する
* 長い説明より、理解 → 実践 → 確認を繰り返す
* 2時間のうち、できるだけ多くを実践に使う
* 最後に小さな成果物を完成させる
* 各セクションに参考URLを明記する

HTML
NotionのDesign Systemを参考にした、シンプルで読みやすい教材UIにしてください。

* Notionライクなタイポグラフィ・余白・階層構造
* 目次
* 学習時間 / 進捗が分かる構成
* Callout
* Code Block
* Checklist
* Table
* Quiz / Exercise
* 参考資料リンク

などを内容に応じて使い分けてください。
装飾しすぎず、**「2時間集中して学習するための実用的な教材」**として設計してください。
HTML/CSS/JavaScriptを1ファイルにまとめ、ブラウザでそのまま開ける完成形として出力してください。
```
